# Third-Party Licenses

This project is licensed under the Apache License 2.0. The third-party
components below keep their own licences. Runtime dependencies are limited to
Apache-2.0, MIT, MIT-0, BSD, EDL, EPL, MPL-2.0, LGPL,
GPL-2.0-with-classpath-exception (the licence of the JDK itself) and public
domain dedications; the build fails on anything else (`license-maven-plugin`). This file is an overview and is updated whenever
a direct dependency is added or removed. The complete list of every bundled
library, including transitive ones, is generated by the build as
`THIRD-PARTY.txt` in each distribution.
