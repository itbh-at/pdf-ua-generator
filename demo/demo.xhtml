All-in-one accessible document example

One template, one set of data, six formats: this document is rendered to PDF/UA, self-contained XHTML, email HTML, DOCX, ODT and plain text, and it is accessible in every one of them.

Text

Hello {customer.name}. Text can be strong, emphasised or use a catalog character style. A phrase in another language is marked as such, so screen readers pronounce it correctly: the German word for accessibility is Barrierefreiheit.Footnotes are real footnotes in PDF, DOCX and ODT, and a linked list at the end in HTML and text.

This paragraph uses the catalog style small.

Layout

Left column

Columns are read in order: first the left column, then the right one.

Right column

In DOCX and ODT they become a layout table; in email HTML a table with role="presentation".

A framed box keeps related content together and is never split across pages.

Links work inside the document — back to the top — and to the outside, e.g. to the IT Beratung Hermann GmbH homepage.

Conclusion
